## 1. 范围（对 UI）

### 1.1 做

1. 错题详情（`/pages/wrong-book/detail`）**恢复**底栏两入口：**复练同类**、**题型变异**（Figma `85:*`）。
2. 复练同类 → 出题设置页预填同知识点；可改设置后发起练习或试卷。
3. 题型变异 → **不**停留设置页；走 **progress → paper**；默认仅练习。
4. 空 KP / KP 不可用：**禁用**对应 CTA + **明确文案**（禁止静默、禁止 Toast 假成功）。
5. 生成中 / 失败：复用既有 progress 态；失败可重试。
6. 保留详情「标记已消灭」（pending 时）；与两入口并存布局以定稿帧为准。

### 1.2 不做

- 新主路径 Tab / 新答题页壳
- 回顾页「再练这 N 道」（wrongSet，另切片；#24 隐藏保持）
- 短信 / 会员 / RAG / Me / 签到 / 主题色 / AI 点评
- 在详情页内嵌答题或同步转圈冒充成卷
- 变异入口提供「考试」快捷（U6）

## 3. 错题详情底栏（恢复规则）

### 3.1 可见性

- #24 隐藏策略结束：两按钮 `visible=true`（或等价从 DOM 恢复）。
- **pending** 与 **cleared**：两入口是否都显示以定稿为准；契约默认 **两种状态均可进复练/变异**（已消灭仍可练习），若定稿仅 pending 显示，以定稿为准并在三行留痕注明。

### 3.2 复练同类按钮

| 条件                                         | UI                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------ |
| `kpIds.length ≥ 1` 且存在同证书可用 `packId` | 可点 → 跳转出题设置（§2）                                          |
| `kpIds` 空，或过滤后无 online KP             | **禁用**；辅助文案例：「该错题暂无可用知识点，无法复练同类」（U2） |
| 无可用 pack                                  | 禁用或点后引导选包；**禁止**静默建临时包                           |
| 证书下架                                     | 禁用；文案对齐现网「证书已下架」                                   |

### 3.3 题型变异按钮

| 条件                                        | UI                                                                   |
| ------------------------------------------- | -------------------------------------------------------------------- |
| 有可用 pack + 错题有可用 KP（同 §契约 5.5） | 可点 → 直接 `POST` create（`source=variant`）→ progress              |
| 空 KP / 无 pack / 证书下架                  | **禁用** + 明确文案（U2）                                            |
| 点击后                                      | 按钮 loading / 防连点；失败 Toast 或留在详情展示错误；**禁止**假成功 |

### 3.4 与「标记已消灭」

- 三按钮并存时的顺序、主次按钮样式：**以 Figma 定稿为准**。
- 消灭成功后的入口态：跟随 §3.1。

## 4. 出题设置页（复练同类）

1. 识别 `from=retrainSimilar`：展示预填知识点芯片/列表（只读或可删减，**不可**加到包外 KP）。
2. 用户删光 KP → 「AI 开始出题」**禁用** + 文案（U2）；**禁止**提交时空 KP 或改走整包。
3. `mode` 默认练习，可切考试（同类允许试卷）。
4. 提交 body：`source: 'retrain_similar'` + `knowledgePointIds` + 既有 settings。
5. 成功 → 既有 progress 流。

---

## 5. 题型变异流（UI）

1. 详情一键发起；**不**打开出题设置改 count（count 固定 1）。
2. 不提供考试模式切换（U6）。
3. progress 文案可区分「正在生成变异题…」（可选）；失败展示服务端 `error.message`。
4. 重试：再 POST 新 session（或回详情再点）；不复活旧 session。
5. 成卷后与普通练习卷同一 paper；交卷进成绩列表（U5）。
6. 答对后详情原错题仍未消灭时：**不**自动改状态；可不额外弹窗（若产品要说明「答对变异不会消灭原错」，作 P1 文案，非阻断）。

## 6. 缺态与文案底线

| 缺态          | 要求                                                  |
| ------------- | ----------------------------------------------------- |
| 空 KP         | 禁用 + 明确文案；禁静默整包；禁 Toast「已开始」       |
| 证书/包不可用 | 禁用或明确错误                                        |
| LLM 未配置    | 创建期 503 文案可展示「出题服务未配置」类（沿用现网） |
| 生成失败      | progress 失败态 + 重试                                |
| 未登录        | 沿用现网引导登录                                      |

像素、色板、间距以 Dev Mode 定稿为准；本约束只钉 **行为与文案底线**。
