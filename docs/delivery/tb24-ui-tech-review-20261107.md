## 5. 技术风险（非阻塞）

1. 预检与 402 竞态：以 402 为准；`checking|posting|sheet_open` 须防抖（契约 §3）。
2. `dailyFreeQuota` 未加法时客户端回退常量 `2` 拼文案，勿阻塞开工。
3. stub 路由须写入 `app.config.ts`，避免 `navigateTo` 失败。
4. 从 C9/C10 返回后应刷新 `GET /me/entitlement` 再允许重试出题（契约 §2.3）。
5. shared browser barrel **不**引入 `node:`（沿用既有）。
