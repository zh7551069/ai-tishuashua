## 检查项

### 小程序 / 客户端限制

- [ ] 无依赖 Web 独有能力（或已有降级方案）
- [ ] 合法域名 / HTTPS / web-view 约束已说明
- [ ] 包体积 / 分包策略可接受
- [ ] 登录、分享、支付等能力与现网配置一致

### 状态是否齐全

- [ ] 加载 / 空 / 错 / 成功
- [ ] 未登录 / 无权限
- [ ] 列表空、分页、失败重试（若适用）

### 接口与字段

- [ ] 页面所需字段在契约中齐全（路径、错误码、分页）
- [ ] 无「稿上有、接口无」的静默缺口
- [ ] 与 UI 强绑定字段已定稿（勿等实现时再猜）

### 权限与安全

- [ ] 角色 / 权限态在稿与契约中对齐
- [ ] 敏感信息展示符合约定

### 性能与列表

- [ ] 长列表有分页或等价策略
- [ ] 大图 / 课件等资源策略可接受
- [ ] 无明显必卡交互（或已接受风险）

### 其他

- [ ] 可复用现有组件 / 布局，无强制推倒重来
- [ ] 与仓库现有技术栈一致
