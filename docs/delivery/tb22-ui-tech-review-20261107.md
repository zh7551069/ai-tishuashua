## 5. 技术风险（非阻塞）

1. 作废 Confirm 须自建；原因与 grant 同校验 1…500。
2. pending 通过：UI 须锁 `qty===pending.qty`，防篡改（契约 §4.3）。
3. revoke 整单事务：前端多选失败时按 400/409 提示，勿乐观局部删行。
4. 审计深链可带当前 `userId` 过滤（契约 §4.5）。
5. 设计包同 HTML 含 TB-21 SKU 抽屉等 — 开工勿扩范围。
