## 5. 技术风险（非阻塞）

1. 稿面大数字「0」与「库存 3」并存 → 实现必须按契约三桶之和，避免照抄稿面 0。
2. entitlement 失败 → ErrorBlock/可重试；**不得**落假「不限场」或假用量。
3. 支付成功从 TB-25/26 返回 → `useDidShow` 重拉，否则会员/库存态滞后。
4. TB-28 stub 路由名工程自决（建议 `pages/commerce/session-ledger/index`）；未注册前点击须友好（toast/占位），勿 silent fail。
5. 签到 local-prefs 与 C13 切换时勿双计；本刀不调用 grant。
6. 可选 skus enrich 失败时档名可走 `skuCode` 约定映射，**勿**为此阻塞页渲染。
7. 勿在 me 树引入 C7 下单工具函数「顺手支付」。
8. shared browser barrel **不**引入 `node:` / 商户私钥读取。
