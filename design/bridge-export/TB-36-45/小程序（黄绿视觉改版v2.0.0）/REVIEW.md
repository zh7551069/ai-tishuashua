## 按影响排序的发现

### P0

**P0-1 首页主图：文件哈希、业务需求标注、稿面标题、画面四者对不上**

- 组别：首页（新）·黄绿；并波及「我（新）」与商业化「我」所用插画。
- 现象：以本包 `images/` 实文件与画面为准——`87ad184d1d47140ad2ff33ab81541b711ae95e1e.png` 目视为**女性**书桌刷题；`44cac9e1d94bf340973772136de0b46c2014f520.png` 目视为**男性**同构书桌。业务需求写「男主图 87ad…、女主图 44cac9e1…」，与画面相反（此前黄绿方案里 87ad 也曾作为「首页女角色书桌」）。稿面标题亦交叉：left 0「多包·男」用了女图 87ad；left 470「多包·女」用了男图 44cac9e1。单包（left 940）与空态（left 1410）都用了 44cac9e1（男图），与「本期默认女主图；单包与空态稿已用女主图」不一致。「我（新）」有数据态 / 主题色预览与商业化「我」三态用的是 87ad（女图），若以画面为准则与「默认女主图」一致，但与业务需求哈希相反。
- 建议：请 Owner 收口「哪张是男 / 女、默认用哪张、稿面标题是否跟文件对调」。在收口前不要改文件、不要按需求文档哈希写死资源映射。截图：`shots/hero-hash-visual-mismatch.png`、`shots/home-four-states.png`。

### P1

**P1-1 周历「今日」设定互相打架**

- 组别：首页、「我（新）」、商业化「我」。
- 现象：首页四态稿面均为「2026年11月12日 · 星期四」，周历 9–15、四=12。这是稿面设定，不当缺陷。但「我（新）」未签到 / 空态把「六」换成「今」，已签到也是周六打勾、周日留空，今日为**周六**。商业化「我」在「日」上标「今天」，今日为**周日**。三处「今天」不是同一天。
- 建议：统一示例日期（建议跟首页周四，或三处改到同一天），并规定周历「今日」的标记方式。不改稿，仅收口。

**P1-2 独立「我（新）」与商业化「我」是两套根页，需定生产 IA**

- 组别：我（新）·黄绿、商业化 v2.0.0（新）·黄绿。
- 现象：两边都是根页「我」——无返回、无底 Tab（不要发明 Tab IA）。骨架相近（身份卡、刷题数 / 正确率 / 连续天数、每日签到、快捷入口），但模块互斥：主题色四档、设置加载失败、空态、页脚「题刷刷 v0.3.0」只在「我（新）」；今日剩余场次 / 会员生效卡、每日分享、邀请有礼、场次明细、签到奖 +1 场或提炼次只在商业化组。签到周历样式也不一样（见 P1-3）。身份文案均为「辉 曾」「备考中 · FDE前沿部署工程师」。
- 建议（设计建议，不是命令）：生产「我」用同一壳，商业化模块作为登录后 / 权益相关的加行与加页，而不是维护两套互斥的「我」。最终以 Owner / Arch 收口为准。对照：`shots/wo-vs-biz-me.png`。

**P1-3 签到周历不是同一组件**

- 组别：我（新）、商业化「我」；亦相对首页周历。
- 现象：首页周历是日期格子（9–15）+ 今日实心。我（新）用圆内对勾表示已签，并以「今」替换星期文案。商业化「我」用星期下方绿线表示已签，并以「今天」角标标在星期上。同是「每日签到」骨架，标记语言两套。
- 建议：收成同一周历组件、不同数据 / 今日强调变体；首页练习周历可共用日历栅格，数据源不同。

**P1-4 「我（新）」身份卡「工程师」被插画裁切**

- 组别：我（新）·黄绿（未签到、已签到）。
- 现象：HTML 文本完整为「备考中 · FDE前沿部署工程师」。画面上插画压住右半，视觉落在「FDE前沿部署工」。商业化「我」同文案在画面上完整可见。旧 Figma 344:4 / 344:158 的残差，在本包「我（新）」导出画面上仍然存在；不是「导出已完整、残差不在本包」。本次不改 344:2。
- 建议：收口身份卡文案与插画的避让（缩字号、换行、或左移插画）。商业化卡已能完整显示，可作参考。

**P1-5 空态「创建刷题包」跳转未写死**

- 组别：首页空态；对照刷题包无包空态。
- 现象：四态都有右上「+」和「开始今日刷题练习」（空态主 CTA 为禁用浅底，仍在）。按辉当面约定，这两处都进入刷题包页（有包进当前包，无包进无包空态）。空态另有「创建刷题包」「或点击右上方 +」。刷题包无包空态 CTA 是「去选包」。稿未写死「创建刷题包」是直达选领域，还是进刷题包空态再「去选包」。
- 建议：请 Owner 收口，评审不替产品拍板。右上浅底人物图标无文案，造形为个人剪影，更像「我」入口而不是性别切换；本期不做性别设置入口，仍建议 Owner 确认该图标去向。

**P1-6 主按钮与部分 CTA 高度 / 圆角未完全一套**

- 组别：多组。
- 现象：主 CTA 多数为高 50、`rounded-[999px]`（开始今日刷题练习、AI 开始出题、今日签到、去刷题、去选包等）。漂移：首页空态「创建刷题包」高 40；刷题包「确认删除」高 48；商业化部分「开通会员」出现 44 / 48；主题色预览「AI 开始出题」高 44（预览可另计）；刷题包「重新选择领域」高 36。
- 建议：主按钮统一一个尺寸 token（建议高 50、全圆、字 15/16 中粗）；次按钮 / 描边按钮、预览缩略、弹层主次按钮另定 1–2 档，不要页面各自写高度。
